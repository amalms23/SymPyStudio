Official Reference Manual

SymPyStudio Documentation & User Guide

Browser-Native Visual Computer Algebra System (CAS) for Undergraduate Physics & Engineering

SymPyStudio combines a typographic mathematical equation editor (MathLive) with a full symbolic computation engine (SymPy running in WebAssembly via Pyodide). You never need to write Python syntax—formulas are entered visually and evaluated symbolically in your browser with persistent memory.

1. Zero-Code Visual Input

Enter fractions, integrals, roots, limits, derivatives, and matrices directly via the top symbol palettes or natural keyboard shortcuts.

2. Persistent CAS Memory

Define constants, variables, or functions in one cell and reference them across your entire notebook—or recall prior outputs with % and %n.

3. Learn SymPy Effortlessly

Every evaluated cell includes a collapsible "Show Equivalent SymPy Code" drawer that reveals the exact Python/SymPy statement behind the result.

1. Persistent Session Memory & %n Referencing

Just like Maple and Wolfram Mathematica, SymPyStudio maintains a continuous Python/SymPy runtime across all cells. Every evaluation increments the execution index (In [1], Out [1], etc.).

Assigning Variables & Functions

  • Inline Variable Assignment: Type k = 4.5 or \omega_0 = \sqrt{\frac{k}{m}} in Standard Evaluate mode.
  • Inline Function Definition: Type f(x) = x^2 \sin(x) or multi-variable V(x,y) = x^2 - y^2. You can then evaluate f(\pi/2) or differentiate f(x) in any later cell.
  • "Assign to" Box: Use the Assign to: input field on the right side of any cell's control bar (e.g., Sol1) to store the output of an integral, derivative, or matrix operation into a variable.

Referencing Previous Outputs (% System)

  • % — References the most recently evaluated output.
  • %1, %2, %n — References the exact output of Out [n], e.g., %1 + 2 \cdot %2.
  • Session Memory Inspector Sidebar: Click any variable or %n item in the right-hand sidebar to insert it directly at your cursor position in the active cell.
  • Pre-Registered Symbols: x, y, z, t, r, θ, φ and physics constants (α, β, γ, δ, ε, ε0, ζ, λ, μ, π, ρ, σ, τ, ψ, ω, ℏ, Δ, ∞) are ready out-of-the-box.

Engineering Continuum Mechanics

3. Solid Mechanics & Theory of Elasticity Suite

Operations: mech_strain, mech_compat, mech_hooke, mech_invariants, mech_airy, mech_mohr

Designed specifically for research and graduate derivations in continuum solid mechanics, elasticity theory, structural analysis, and yield surface failure modeling.

1. Kinematics & Saint-Venant Compatibility

Small-Strain Tensor: Given displacement field $\mathbf{u} = [u(x,y,z), v(x,y,z), w(x,y,z)]^T$:

εij = ½ (∂ui/∂xj + ∂uj/∂xi), &quad; γxy = 2 εxy

Saint-Venant Compatibility Condition: In simply-connected domains, a symmetric tensor field $\boldsymbol{\varepsilon}$ corresponds to a single-valued, continuous displacement field $\mathbf{u}$ if and only if its compatibility curvature tensor vanishes identically:

∇ × (∇ × ε)T = 0

In 2D: $\frac{\partial^2 \varepsilon_{xx}}{\partial y^2} + \frac{\partial^2 \varepsilon_{yy}}{\partial x^2} - 2\frac{\partial^2 \varepsilon_{xy}}{\partial x \partial y} = 0$. In 3D: all 6 compatibility equations ($S_{11}, S_{22}, S_{33}, S_{12}, S_{23}, S_{31}$) must equal zero.

2. Generalized Isotropic Hooke's Law

Relates Cauchy stress tensor $\boldsymbol{\sigma}$ and strain tensor $\boldsymbol{\varepsilon}$ via elastic modulus $E$ and Poisson's ratio $\nu$:

  • Plane Stress ($\sigma_{zz} = 0$): Thin plates loaded in-plane:
    σxx = &frac{E}{1-ν²} (εxx + νεyy), &quad; τxy = &frac{E}{1+ν} εxy
  • Plane Strain ($\varepsilon_{zz} = 0$): Thick structures, dams, tunnels:
    σxx = &frac{E}{(1+ν)(1-2ν)} [(1-ν)εxx + νεyy], &quad; σzz = ν(σxx + σyy)
  • 3D Isotropic Media: $\boldsymbol{\sigma} = 2\mu \boldsymbol{\varepsilon} + \lambda \mathrm{tr}(\boldsymbol{\varepsilon})\mathbf{I}$ with Lamé constants $\lambda = \frac{E\nu}{(1+\nu)(1-2\nu)}$ and $\mu = G = \frac{E}{2(1+\nu)}$.

3. Stress Invariants & von Mises Yield Stress

Given Cauchy stress $\boldsymbol{\sigma}$, the hydrostatic mean stress is $\sigma_m = \frac{1}{3}\mathrm{tr}(\boldsymbol{\sigma})$, and the deviatoric stress tensor is $\mathbf{S} = \boldsymbol{\sigma} - \sigma_m \mathbf{I}$.

Fundamental Invariants:

I1 = tr(σ) = σxx + σyy + σzz
I2 = ½ [I1² - tr(σ²)]
I3 = det(σ)
J2 = ½ tr(S²) = ⅓ I1² - I2
σvm = √(3 J2) = √(½[(σ1-σ2)² + (σ2-σ3)² + (σ3-σ1)²])

von Mises yielding occurs when $\sigma_{vm} \ge \sigma_y$. Tresca criterion occurs when $\tau_{max} = \frac{\sigma_1 - \sigma_3}{2} \ge \tau_y$.

4. Airy Stress Functions & Mohr's Circle Plot

Airy Potential $\Phi(x, y)$: Satisfies exact Cauchy equilibrium in the absence of body forces:

σxx = ∂²Φ/∂y², &quad; σyy = ∂²Φ/∂x², &quad; τxy = -∂²Φ/∂x∂y

The biharmonic governing equation ensures compatibility: $\nabla^4\Phi = \frac{\partial^4\Phi}{\partial x^4} + 2\frac{\partial^4\Phi}{\partial x^2 \partial y^2} + \frac{\partial^4\Phi}{\partial y^4} = 0$.

Mohr's Circle Plot: Enter $[\sigma_x, \sigma_y, \tau_{xy}]$ to obtain principal stresses $\sigma_1, \sigma_2 = \sigma_{avg} \pm R$, max shear $\tau_{max} = R$, and orientation angle $\theta_p = \frac{1}{2}\mathrm{atan2}(2\tau_{xy}, \sigma_x - \sigma_y)$ alongside a proportional Plotly circle with diameter line and state markers.

Concrete Example: Cantilever Beam with Tip Load P

Airy polynomial potential $\Phi(x, y) = -\frac{P}{2 I} x y^2 + \frac{P}{6 I} y^3$. Enter this in a cell and select Airy Stress Φ:

Input (Airy Function): -\frac{P}{2 I} x y^2 + \frac{P}{6 I} y^3
Output (Cauchy Stress Tensor): σxx = -\frac{P x y}{I}, &quad; σyy = 0, &quad; τxy = \frac{P}{2 I} y^2
Theoretical & Applied Field Theory

4. Electrodynamics & Curvilinear Field Theory Suite

Operations: curv_grad, curv_div, curv_curl, curv_laplacian, em_maxwell_check, em_potentials, em_gauge, em_poynting, em_stress_tensor, em_field_plot

End-to-end vector calculus across orthogonal curvilinear coordinate systems, electromagnetic radiation potentials, gauge invariance verifications, energy-momentum tensors, and field line quiver plotting.

1. Curvilinear Vector Calculus (∇, ∇·, ∇×, ∇²)

Supports metric scale factors $h_1, h_2, h_3$ for orthogonal coordinates $(u_1, u_2, u_3)$:

  • Cartesian $(x, y, z)$: $h = [1, 1, 1]$
  • Cylindrical $(r, \theta, z)$: $h = [1, r, 1]$
  • Spherical $(r, \theta, \phi)$: $h = [1, r, r\sin\theta]$

General Formulae:

∇φ = ∑i (1/hi) (∂φ/∂ui) êi
∇·F = &frac{1}{h1h2h3} [∂(h2h3F1)/∂u1 + ∂(h1h3F2)/∂u2 + ∂(h1h2F3)/∂u3]
∇²φ = &frac{1}{h1h2h3} ∑i ∂/∂ui [(h1h2h3/hi²) ∂φ/∂ui]

2. Maxwell's Equations Verifier

Input candidate fields $[\mathbf{E}, \mathbf{B}]$ or pass source distributions $\rho, \mathbf{J}$ to verify the 4 fundamental laws of electromagnetism:

1. Gauss's Law: ∇·E = ρ / ε0
2. Gauss's Law for Magnetism: ∇·B = 0
3. Faraday's Law: ∇×E + ∂B/∂t = 0
4. Ampère-Maxwell Law: ∇×B - μ0ε0 ∂E/∂t = μ0 J

The verifier outputs whether each law is identically satisfied (residual zero) or shows the required source distribution.

3. Potentials & Gauge Transformations

Express fields in terms of magnetic vector potential $\mathbf{A}(t, \mathbf{x})$ and electric scalar potential $V(t, \mathbf{x})$:

B = ∇ × A,   E = -∇V - ∂A/∂t

Gauge Fixing & Invariance:

  • Lorenz Gauge: $\nabla \cdot \mathbf{A} + \frac{1}{c^2}\frac{\partial V}{\partial t} = 0$ (decouples wave equations into $\Box \mathbf{A} = -\mu_0\mathbf{J}$ and $\Box V = -\rho/\varepsilon_0$).
  • Coulomb Gauge: $\nabla \cdot \mathbf{A} = 0$ (transverse gauge, ideal for magnetostatics and quantum optics).

4. Poynting Vector & Maxwell Stress Tensor

Poynting Energy Flux Vector & Energy Density:

S = &frac{1}{μ0} (E × B),   u = ½ (ε0 |E|² + &frac{1}{μ0} |B|²)

Maxwell Stress Tensor $T_{ij}$ & Force Density:

Tij = ε0 [Ei Ej - ½δij E²] + &frac{1}{μ0} [Bi Bj - ½δij B²]

Total electromagnetic body force density: $\mathbf{f} = \nabla \cdot \mathbf{T} - \varepsilon_0\mu_0 \frac{\partial\mathbf{S}}{\partial t}$.

Concrete Example: TEM Propagating Electromagnetic Wave

Enter transverse fields $\mathbf{E} = [E_0 \cos(k z - \omega t), 0, 0]$ and $\mathbf{B} = [0, \frac{E_0}{c} \cos(k z - \omega t), 0]$, and select Poynting Flux (S, u):

Poynting Vector $\mathbf{S}$: S = [0, 0, \frac{E_0^2}{\mu_0 c} \cos^2(kz - \omega t)]^T
EM Energy Density $u$: u = \varepsilon_0 E_0^2 \cos^2(kz - \omega t)
