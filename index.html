Official Reference Manual

SymPyStudio Documentation & User Guide

Browser-Native Visual Computer Algebra System (CAS) for Undergraduate Physics & Engineering

SymPyStudio combines a typographic mathematical equation editor (MathLive) with a full symbolic computation engine (SymPy running in WebAssembly via Pyodide). You never need to write Python syntax—formulas are entered visually and evaluated symbolically in your browser with persistent memory.

1. Zero-Code Visual Input

Enter fractions, integrals, roots, limits, derivatives, and matrices directly via the top symbol palettes or natural keyboard shortcuts.

2. Persistent CAS Memory

Define constants, variables, or functions in one cell and reference them across your entire notebook—or recall prior outputs with % and %n.

3. Learn SymPy Effortlessly

Every evaluated cell includes a collapsible "Show Equivalent SymPy Code" drawer that reveals the exact Python/SymPy statement behind the result.

1. Persistent Session Memory & %n Referencing

Just like Maple and Wolfram Mathematica, SymPyStudio maintains a continuous Python/SymPy runtime across all cells. Every evaluation increments the execution index (In [1], Out [1], etc.).

Assigning Variables & Functions

  • Inline Variable Assignment: Type k = 4.5 or \omega_0 = \sqrt{\frac{k}{m}} in Standard Evaluate mode.
  • Inline Function Definition: Type f(x) = x^2 \sin(x) or multi-variable V(x,y) = x^2 - y^2. You can then evaluate f(\pi/2) or differentiate f(x) in any later cell.
  • "Assign to" Box: Use the Assign to: input field on the right side of any cell's control bar (e.g., Sol1) to store the output of an integral, derivative, or matrix operation into a variable.

Referencing Previous Outputs (% System)

  • % — References the most recently evaluated output.
  • %1, %2, %n — References the exact output of Out [n], e.g., %1 + 2 \cdot %2.
  • Session Memory Inspector Sidebar: Click any variable or %n item in the right-hand sidebar to insert it directly at your cursor position in the active cell.
  • Pre-Registered Symbols: x, y, z, t, r, θ, φ and physics constants (α, β, γ, δ, ε, ε0, ζ, λ, μ, π, ρ, σ, τ, ψ, ω, ℏ, Δ, ∞) are ready out-of-the-box.

2. Categorized Operations Ribbon Reference

Clicking any operation in Tabs 1–5 configures the currently active notebook cell (Target: In[n]) and displays specialized parameter fields below the math editor.

Ribbon Tab Operation Parameters & Usage Underlying SymPy Function
1. Calculus & Analysis Differentiate Specify differentiation variable (x, y, t) and order n (1st, 2nd, $n$-th derivative). sp.diff(expr, var, order)
Indefinite Integral Computessymbolic antiderivative $\int f(x)\,dx$ with respect to the chosen variable. sp.integrate(expr, var)
Definite Integral Computes $\int_a^b f(x)\,dx$. Supports symbolic bounds like 0, pi, oo ($\infty$), or -oo. sp.integrate(expr, (var, a, b))
Limit Evaluates $\lim_{x \to a} f(x)$ with direction flags: Two-sided (+-), Right (+), or Left (-). sp.limit(expr, var, a, dir)
Taylor / Series Power series expansion around point $x_0$ up to order $O(x^n)$. sp.series(expr, var, x0, n)
Symbolic Summation Closed-form summation $\sum_{n=a}^{b} f(n)$ (e.g., Riemann zeta or geometric series to oo). sp.summation(expr, (n, a, b))
2. Algebra & Solvers Solve for Variable Finds analytical roots of $f(x) = g(x)$ (or $f(x) = 0$ if no = is written) for target unknown. sp.solve(Eq(lhs, rhs), var)
Simultaneous Solver Enter 1st equation in the main editor, 2nd & 3rd equations in the parameter boxes, and comma-separated unknowns (e.g., x, y). sp.solve([eq1, eq2, ...], vars)
Simplify / Expand / Factor / Apart / TrigSimp Algebraic rewrites, polynomial factoring, partial fraction decomposition (apart), and trigonometric reduction. sp.simplify / expand / factor / apart / trigsimp

3. Linear Algebra, Matrices & Vector Calculus (Tab 3)

Constructing & Operating on Matrices

Use the 2×2 Grid, 3×3 Grid, 4×4 Grid buttons or open the interactive Visual Matrix Builder modal to populate rows and columns with numbers or symbolic variables.

  • Operations: det(A), Inverse A⁻¹, Transpose Aᵀ, Trace, Characteristic Polynomial p(λ), and symbolic Eigenvalues & Eigenvectors.
  • Tip: Assign a matrix to a symbol like M using the Assign to field, then compute M's inverse or eigenvalues in the next cell!

Cartesian Vector Calculus (∇ Operators)

  • Gradient (∇φ) & Laplacian (∇²φ): Enter any scalar field (e.g., x^2 y + \sin(z)) and select Grad or Laplacian.
  • Divergence (∇·F) & Curl (∇×F): Enter a 3-component vector either as a bracketed list [x^2, y z, -z^2] or a $3\times 1$ matrix, then click Div or Curl.

4. Differential Equations (ODE) & Interactive Plotting (Tabs 4 & 5)

1st & 2nd Order ODE Solver (sp.dsolve)

Write differential equations using prime notation y''(x) + 2 y'(x) + 10 y(x) = 0 (or click one of the built-in Physics/RLC ODE templates in Tab 4).

  • Initial / Boundary Conditions: Fill in IC 1 (e.g., y(0)=1) and IC 2 (e.g., y'(0)=0) to automatically solve for integration constants $C_1, C_2$.

2D Curves & 3D Surfaces (sp.lambdify + Plotly)

Symbolic expressions are compiled into fast numerical functions via sp.lambdify and rendered interactively with zoom, pan, and 3D orbital rotation.

  • Click "Plot Result" on any cell output (including solved ODEs!) to automatically create a plot cell referencing that output.
