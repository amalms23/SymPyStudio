1. Architectural Overview & Execution Pipeline

Unlike cloud-hosted notebooks (JupyterHub, Google Colab), SymPyStudio computes inside your browser: SymPy runs in WebAssembly in a background Web Worker on your own CPU, and your expressions are never sent to a server. The page does download its libraries and the Python runtime from public CDNs (cached after the first visit).

1. Input Pipeline MathLive • AST

Captures formula glyphs through a virtual keyboard or physical keystrokes into a reactive MathJSON/LaTeX DOM tree. The built-in tokenizer auto-converts math syntax (\int_a^b, \frac{d}{dx}, \nabla) into parsed expression trees.

2. CAS Kernel Pyodide • SymPy 1.12

WebAssembly build of CPython 3.12 (Pyodide 0.26.1) with SymPy 1.12 and mpmath, running in a Web Worker so long computations never freeze the page. All variables, user functions, and evaluation output registries persist across notebook cells with arbitrary-precision arithmetic.

3. Presentation Layer KaTeX • Plotly.js

Symbolic results are typeset into mathematical typography using KaTeX. Numerical arrays are compiled via sp.lambdify into vectorized JavaScript functions for responsive 2D/3D Plotly rendering.

How Input Is Read

After each evaluation the cell shows Parsed as, i.e. what the parser understood, plus a warning whenever it had to guess. If a result looks wrong, check that line first.

  • E and I are ordinary symbols, so $\frac{PL^3}{3EI}$ is the cantilever deflection. e is Euler's number and i the imaginary unit; both can be switched off under Memory → Input & Kernel Settings, and a sum index such as $\sum_{i=1}^{n}$ always wins.
  • Letters next to each other multiply ($xy = x\cdot y$). A run of letters becomes one name only if that name is already defined (e.g. after mass = 5); write \mathrm{mass} to force it.
  • Integrals need a differential: $\int_0^1 x^2\,dx$, $\int \frac{dx}{x}$, $\int_0^1\int_0^x y\,dy\,dx$. Derivatives: $\frac{d}{dx}(\dots)$, $\frac{dy}{dx}$, $\frac{\partial^2}{\partial x\partial y}(\dots)$, $f'(x)$.
  • $\sin^{-1}x$ is $\arcsin x$; $\ln x$ and $\log x$ are natural logs, and $\log_{2} 8 = 3$.
  • In Python code cells SymPy's own rules apply: there E is Euler's number and I is $\sqrt{-1}$.

2.1 Variable Assignment & Function Definition

Just like Maple, Wolfram Mathematica, and MATLAB, SymPyStudio retains all assigned symbols and user functions across subsequent cells. You do not need to repeat symbol definitions.

Method A: Inline Assignment Equation Standard Evaluate Mode

Type an equality equation in any cell with the variable on the left-hand side. The right-hand side is evaluated and bound to that symbol in the global kernel memory:

# Scalar variable assignment:
k = 4.5 \cdot 10^3 → k = 4500.0
# Symbolic expression assignment:
\omega_0 = \sqrt{\frac{k}{m}} → \omega_0 = \sqrt{k/m}
# In subsequent cells, evaluate directly:
2 \cdot \pi \cdot \omega_0
Method B: "Assign:" Control Box Any Operation Mode

Every cell control bar features an Assign: input box on the right. When specified, the output of any calculus, linear algebra, or physics operation is automatically stored into that variable name:

Cell input: \int x^3 \sin(x) \, dx
Operation: integrate_indef, Assign: Sol1
Output: Result is typeset, and Sol1 appears immediately in the Session Memory Sidebar.

Defining Single-Variable & Multi-Variable Mathematical Functions Callable Function Architecture

Define mathematical functions visually using function notation f(x) = \dots or multi-variable V(x, y) = \dots. The kernel creates a callable lambda expression that supports exact evaluation, differentiation, and plotting in subsequent cells:

1. Function Definition: f(x) = x^2 \sin(x)
2. Specific Evaluation: f\left(\frac{\pi}{2}\right) \implies \frac{\pi^2}{4}
3. Derivative of Function: \frac{d}{dx}\left(f(x)\right) \implies 2x\sin(x) + x^2\cos(x)

2.2 The % Output Referencing System (Mathematica & Maple Pipeline)

Every evaluated cell is assigned sequential execution labels: In [n] and Out [n]. You can reference previous outputs in new formulas without re-typing or copy-pasting equations.

Syntax Meaning Worked Example Evaluation Behavior

2.3 Symbolic Domain Assumptions (sp.symbols Flags)

In pure mathematics, symbols are assumed to be complex numbers ($\mathbb{C}$) by default. In physics and engineering, variables represent real physical quantities (lengths $L > 0$, masses $m > 0$, time $t \ge 0$, wave modes $n \in \mathbb{N}$). Without assumptions, CAS engines cannot simplify expressions like $\sqrt{x^2} = x$ or resolve infinite integrals.

Without Assumptions (Default Complex $\mathbb{C}$)

  • \sqrt{x^2} → Evaluates to \sqrt{x^2} (cannot assume $x \ge 0$).
  • \int_0^\infty e^{-a x} \, dx → Fails or throws conditional piecewise branches depending on whether $\mathrm{Re}(a) > 0$.
  • \cos(2\pi n) → Unsimplified (cannot assume $n$ is an integer).

With Domain Assumptions Applied (Sidebar Manager)

  • positive=True on $x$: \sqrt{x^2} → Simplifies cleanly to x.
  • positive=True on $a$: \int_0^\infty e^{-a x} \, dx → Evaluates directly to \frac{1}{a}.
  • integer=True on $n$: \cos(2\pi n) → Evaluates directly to 1.
How to apply assumptions in the UI:

Open the Session Memory Sidebar (or click Memory in the top header) → expand "Domain Assumptions (sp.symbols)" → enter variable names separated by commas (e.g. x, y, L, m) → check positive, real, integer, or nonzero → click Apply. Active assumptions appear as colored badges and are synchronized across your notebook session.

4. Solid Mechanics & Theory of Elasticity Reference

Mathematical formulations, governing tensor differential equations, constitutive relations, yield criteria, and Airy stress potentials.

Suite 1: Continuum Elasticity

4.1 Kinematics: Infinitesimal Strain Tensor & Saint-Venant Compatibility

In linear continuum mechanics, deformations of a solid body are described by the displacement vector field $\mathbf{u}(\mathbf{x}) = [u, v, w]^T$. Under the small-strain assumption ($||\nabla \mathbf{u}|| \ll 1$), the non-linear Green-Lagrange strain tensor reduces to the symmetric Cauchy infinitesimal strain tensor:

Small-Strain Tensor Definition (mech_strain):
\varepsilon_{ij} = \frac{1}{2} \left( \frac{\partial u_i}{\partial x_j} + \frac{\partial u_j}{\partial x_i} \right)
\boldsymbol{\varepsilon} = \begin{bmatrix} \frac{\partial u}{\partial x} & \frac{1}{2}\left(\frac{\partial u}{\partial y} + \frac{\partial v}{\partial x}\right) & \frac{1}{2}\left(\frac{\partial u}{\partial z} + \frac{\partial w}{\partial x}\right) \\ \frac{1}{2}\left(\frac{\partial v}{\partial x} + \frac{\partial u}{\partial y}\right) & \frac{\partial v}{\partial y} & \frac{1}{2}\left(\frac{\partial v}{\partial z} + \frac{\partial w}{\partial y}\right) \\ \frac{1}{2}\left(\frac{\partial w}{\partial x} + \frac{\partial u}{\partial z}\right) & \frac{1}{2}\left(\frac{\partial w}{\partial y} + \frac{\partial v}{\partial z}\right) & \frac{\partial w}{\partial z} \end{bmatrix}

Engineering shear strain is defined as $\gamma_{ij} = 2\varepsilon_{ij} = \frac{\partial u_i}{\partial x_j} + \frac{\partial u_j}{\partial x_i}$.

Saint-Venant Compatibility Theorem (mech_compat):
\nabla \times (\nabla \times \boldsymbol{\varepsilon})^T = \mathbf{0} \quad \text{or} \quad \mathrm{inc}(\boldsymbol{\varepsilon}) = \mathbf{0}
2D In-Plane Condition (Residual $R$):
R = \frac{\partial^2 \varepsilon_{xx}}{\partial y^2} + \frac{\partial^2 \varepsilon_{yy}}{\partial x^2} - 2\frac{\partial^2 \varepsilon_{xy}}{\partial x \partial y} = 0

Theorem: In a simply-connected domain, a symmetric strain field $\boldsymbol{\varepsilon}$ integrates to a continuous, single-valued displacement field $\mathbf{u}$ if and only if all compatibility residuals vanish identically.

4.2 Generalized Isotropic Hooke's Law (Voigt Matrix Form)

Relates Cauchy stress tensor $\boldsymbol{\sigma}$ and strain tensor $\boldsymbol{\varepsilon}$ via elastic modulus $E$ and Poisson's ratio $\nu$. The mech_hooke operation supports both conversion directions (strain_to_stress $\boldsymbol{\sigma} = \mathbf{C}\boldsymbol{\varepsilon}$ and stress_to_strain $\boldsymbol{\varepsilon} = \mathbf{S}\boldsymbol{\sigma}$) across standard planar states:

1. Plane Stress ($\sigma_{zz} = 0$)

Thin plates loaded in their plane (e.g. membranes, web plates):

\begin{bmatrix} \sigma_{xx} \\ \sigma_{yy} \\ \tau_{xy} \end{bmatrix} = \frac{E}{1-\nu^2} \begin{bmatrix} 1 & \nu & 0 \\ \nu & 1 & 0 \\ 0 & 0 & \frac{1-\nu}{2} \end{bmatrix} \begin{bmatrix} \varepsilon_{xx} \\ \varepsilon_{yy} \\ \gamma_{xy} \end{bmatrix}
εzz = -\frac{\nu}{E}(\sigma_{xx} + \sigma_{yy})
2. Plane Strain ($\varepsilon_{zz} = 0$)

Thick bodies constrained in $z$ (e.g. dams, tunnels, long pipes):

\begin{bmatrix} \sigma_{xx} \\ \sigma_{yy} \\ \tau_{xy} \end{bmatrix} = \frac{E}{(1+\nu)(1-2\nu)} \begin{bmatrix} 1-\nu & \nu & 0 \\ \nu & 1-\nu & 0 \\ 0 & 0 & \frac{1-2\nu}{2} \end{bmatrix} \begin{bmatrix} \varepsilon_{xx} \\ \varepsilon_{yy} \\ \gamma_{xy} \end{bmatrix}
σzz = \nu(\sigma_{xx} + \sigma_{yy})
3. 3D Isotropic Elasticity

General triaxial continuum state with LamÃ© parameters $\lambda, \mu$:

\boldsymbol{\sigma} = 2\mu \boldsymbol{\varepsilon} + \lambda \mathrm{tr}(\boldsymbol{\varepsilon}) \mathbf{I}
\lambda = \frac{E\nu}{(1+\nu)(1-2\nu)}, \quad \mu = G = \frac{E}{2(1+\nu)}

4.3 Stress Invariants, Deviatoric Tensors & von Mises Yield Criterion (mech_invariants)

Given symmetric Cauchy stress tensor $\boldsymbol{\sigma} \in \mathbb{R}^{3 \times 3}$, hydrostatic mean stress is $\sigma_m = \frac{1}{3}\mathrm{tr}(\boldsymbol{\sigma})$, and the deviatoric stress tensor is $\mathbf{S} = \boldsymbol{\sigma} - \sigma_m \mathbf{I}$. Plastic yielding in ductile metals is independent of hydrostatic pressure and governed solely by deviatoric distortion ($J_2$):

Fundamental Stress Invariants:
I_1 = \mathrm{tr}(\boldsymbol{\sigma}) = \sigma_{xx} + \sigma_{yy} + \sigma_{zz} = \sigma_1 + \sigma_2 + \sigma_3
I_2 = \frac{1}{2}\left( I_1^2 - \mathrm{tr}(\boldsymbol{\sigma}^2) \right) = \sigma_1\sigma_2 + \sigma_2\sigma_3 + \sigma_3\sigma_1
I_3 = \det(\boldsymbol{\sigma}) = \sigma_1 \sigma_2 \sigma_3
Deviatoric Invariant $J_2$ & Yield Criteria:
J_2 = \frac{1}{2}\mathrm{tr}(\mathbf{S}^2) = \frac{1}{3}I_1^2 - I_2 = \frac{1}{6}[(\sigma_1-\sigma_2)^2 + (\sigma_2-\sigma_3)^2 + (\sigma_3-\sigma_1)^2]
\sigma_{\mathrm{vm}} = \sqrt{3 J_2} \ge \sigma_y \quad \text{(von Mises Yielding)}
\tau_{\max} = \frac{\sigma_1 - \sigma_3}{2} \ge \tau_y = \frac{\sigma_y}{2} \quad \text{(Tresca Yielding)}

Airy Stress Function $\Phi(x, y)$ (mech_airy)

Automatically satisfies Cauchy equilibrium equations $\frac{\partial\sigma_{xx}}{\partial x} + \frac{\partial\tau_{xy}}{\partial y} = 0$ and $\frac{\partial\tau_{xy}}{\partial x} + \frac{\partial\sigma_{yy}}{\partial y} = 0$ in the absence of body forces:

\sigma_{xx} = \frac{\partial^2\Phi}{\partial y^2}, \quad \sigma_{yy} = \frac{\partial^2\Phi}{\partial x^2}, \quad \tau_{xy} = -\frac{\partial^2\Phi}{\partial x \partial y}

Biharmonic Compatibility: To guarantee an elastic displacement field, $\Phi$ must satisfy $\nabla^4\Phi = \frac{\partial^4\Phi}{\partial x^4} + 2\frac{\partial^4\Phi}{\partial x^2 \partial y^2} + \frac{\partial^4\Phi}{\partial y^4} = 0$.

Mohr's Circle Principal Stress Analysis (mech_mohr)

Input 2D state $[\sigma_x, \sigma_y, \tau_{xy}]$. Evaluates analytical center, radius, principal stresses, and principal orientation angle $\theta_p$:

\sigma_{\mathrm{avg}} = \frac{\sigma_x + \sigma_y}{2}, \quad R = \sqrt{\left(\frac{\sigma_x-\sigma_y}{2}\right)^2 + \tau_{xy}^2}
\sigma_1, \sigma_2 = \sigma_{\mathrm{avg}} \pm R, \quad \tau_{\max} = R
\theta_p = \frac{1}{2}\operatorname{atan2}(2\tau_{xy}, \sigma_x - \sigma_y)

Automatically renders an interactive Plotly Mohr circle with coordinate markers for $(\sigma_x, -\tau_{xy})$, $(\sigma_y, \tau_{xy})$, and principal stresses $(\sigma_1, 0), (\sigma_2, 0)$.

Suite 2: Field Theory

5.1 Orthogonal Curvilinear Metric Scale Factors ($h_1, h_2, h_3$) & Vector Operators

In an orthogonal curvilinear coordinate system $(u_1, u_2, u_3)$, the differential displacement is $d\mathbf{r} = h_1 du_1 \hat{e}_1 + h_2 du_2 \hat{e}_2 + h_3 du_3 \hat{e}_3$, with metric scale factors $h_i = ||\frac{\partial\mathbf{r}}{\partial u_i}||$:

Coordinate System Coordinates $(u_1, u_2, u_3)$ Scale Factors $h = [h_1, h_2, h_3]$ Volume Element $dV$
Cartesian (x, y, z) [1, 1, 1] dx \, dy \, dz
Cylindrical (r, \theta, z) [1, r, 1] r \, dr \, d\theta \, dz
Spherical (r, \theta, \phi) [1, r, r\sin\theta] r^2\sin\theta \, dr \, d\theta \, d\phi
Gradient $\nabla\phi$ (curv_grad) & Divergence $\nabla\cdot\mathbf{F}$ (curv_div):
\nabla\phi = \sum_{i=1}^3 \frac{1}{h_i} \frac{\partial\phi}{\partial u_i} \hat{e}_i
\nabla\cdot\mathbf{F} = \frac{1}{h_1 h_2 h_3} \left[ \frac{\partial(h_2 h_3 F_1)}{\partial u_1} + \frac{\partial(h_1 h_3 F_2)}{\partial u_2} + \frac{\partial(h_1 h_2 F_3)}{\partial u_3} \right]
Curl $\nabla\times\mathbf{F}$ (curv_curl) & Laplacian $\nabla^2\phi$ (curv_laplacian):
\nabla\times\mathbf{F} = \frac{1}{h_1 h_2 h_3} \begin{vmatrix} h_1\hat{e}_1 & h_2\hat{e}_2 & h_3\hat{e}_3 \\ \partial/\partial u_1 & \partial/\partial u_2 & \partial/\partial u_3 \\ h_1 F_1 & h_2 F_2 & h_3 F_3 \end{vmatrix}
\nabla^2\phi = \frac{1}{h_1 h_2 h_3} \sum_{i=1}^3 \frac{\partial}{\partial u_i}\left( \frac{h_1 h_2 h_3}{h_i^2} \frac{\partial\phi}{\partial u_i} \right)

5.2 Maxwell's Differential Equations Verifier (em_maxwell_check)

Input candidate electric and magnetic fields as a matrix or pair $[\mathbf{E}, \mathbf{B}]$. The verifier symbolically differentiates each vector field with respect to coordinates $(x, y, z)$ and time $t$, computing exact residuals against the 4 fundamental equations of electrodynamics:

1. Gauss's Law:
\nabla\cdot\mathbf{E} - \frac{\rho}{\varepsilon_0} = 0
2. Gauss's Law for Magnetism:
\nabla\cdot\mathbf{B} = 0 \quad \text{(No Magnetic Monopoles)}
3. Faraday's Law of Induction:
\nabla\times\mathbf{E} + \frac{\partial\mathbf{B}}{\partial t} = \mathbf{0}
4. Ampère-Maxwell Law:
\nabla\times\mathbf{B} - \mu_0\varepsilon_0\frac{\partial\mathbf{E}}{\partial t} - \mu_0\mathbf{J} = \mathbf{0}

5.3 Retarded Potentials ($\mathbf{A}, V$) & Gauge Conditions (em_potentials, em_gauge)

The two homogeneous Maxwell equations ($\nabla\cdot\mathbf{B} = 0$ and $\nabla\times\mathbf{E} + \partial_t\mathbf{B} = \mathbf{0}$) guarantee the existence of a magnetic vector potential $\mathbf{A}(t, \mathbf{x})$ and electric scalar potential $V(t, \mathbf{x})$:

Field Recovery from Potentials (em_potentials):
\mathbf{B} = \nabla \times \mathbf{A}
\mathbf{E} = -\nabla V - \frac{\partial\mathbf{A}}{\partial t}

Fields are invariant under gauge transformations: $\mathbf{A}' = \mathbf{A} + \nabla\chi, \; V' = V - \frac{\partial\chi}{\partial t}$.

Gauge Invariance Verifier (em_gauge):
Lorenz Gauge Condition:
R_{\text{Lorenz}} = \nabla\cdot\mathbf{A} + \frac{1}{c^2}\frac{\partial V}{\partial t} = 0
Coulomb (Transverse) Gauge:
R_{\text{Coulomb}} = \nabla\cdot\mathbf{A} = 0

5.4 Energy & Momentum: Poynting Theorem & Maxwell Stress Tensor

Poynting Energy Flux Vector & Density (em_poynting):
\mathbf{S} = \frac{1}{\mu_0} (\mathbf{E} \times \mathbf{B}) \quad \text{[Energy Flux Density } \mathrm{W/m^2}\text{]}
u = \frac{1}{2} \varepsilon_0 |\mathbf{E}|^2 + \frac{1}{2\mu_0} |\mathbf{B}|^2 \quad \text{[Energy Density } \mathrm{J/m^3}\text{]}
\mathbf{g} = \mu_0\varepsilon_0 \mathbf{S} = \frac{\mathbf{S}}{c^2} \quad \text{[Momentum Density } \mathrm{N\cdot s/m^3}\text{]}

Poynting's Theorem: $\frac{\partial u}{\partial t} + \nabla\cdot\mathbf{S} = -\mathbf{J}\cdot\mathbf{E}$ (rate of electromagnetic work).

Maxwell Stress Tensor & Force Density (em_stress_tensor):
T_{ij} = \varepsilon_0\left(E_i E_j - \frac{1}{2}\delta_{ij}E^2\right) + \frac{1}{\mu_0}\left(B_i B_j - \frac{1}{2}\delta_{ij}B^2\right)
\mathbf{f}_{\mathrm{EM}} = \nabla\cdot\mathbf{T} - \varepsilon_0\mu_0\frac{\partial\mathbf{S}}{\partial t} = \rho\mathbf{E} + \mathbf{J}\times\mathbf{B}

Computes radiation pressure and electromagnetic forces via surface integral $\mathbf{F} = \oint \mathbf{T} \cdot d\mathbf{a}$.

Case Study 1: Tip-Loaded Cantilever Beam (Elasticity & Mohr's Circle) Template: suite_solid_cantilever

Problem: A narrow cantilever beam of length $L$ and height $h$ carries a vertical shear force $P$ at its free tip $x = 0$. Using the Airy stress function $\Phi(x, y) = -\frac{P}{2I} x y^2 + \frac{P}{6I} y^3$, derive Cauchy stresses and analyze the state of stress at the clamped root surface $(x=0, y=h/2)$.

1. Input: \Phi(x, y) = -\frac{P}{2I} x y^2 + \frac{P}{6I} y^3 → Operation: mech_airy
2. Verified: Biharmonic $\nabla^4\Phi = 0$ is identically satisfied ($0$). Stress tensor: $\sigma_{xx} = -\frac{Pxy}{I}$, $\sigma_{yy} = 0$, $\tau_{xy} = \frac{P}{2I}(\frac{h^2}{4} - y^2)$.
3. Clamped surface evaluation: At $x=0, y=h/2$, stress state is pure shear $[\sigma_x=0, \sigma_y=0, \tau_{xy}=\tau_0]$. Mohr circle reveals $\sigma_1 = +\tau_0, \sigma_2 = -\tau_0$ inclined at $45^\circ$.
Case Study 2: Thick-Walled Pressurized Cylinder & von Mises Yielding Template: suite_solid_pressurized_cylinder

Problem: A thick cylinder with inner radius $a$, outer radius $b$, and internal pressure $P_i$. Solve the polar Navier displacement equation and verify von Mises yield stress at the inner bore where stress concentration is maximum.

1. Radial equilibrium equation: \frac{d^2 u}{dr^2} + \frac{1}{r}\frac{du}{dr} - \frac{u}{r^2} = 0 → Solved via ode_solve.
2. LamÃ© stress solutions: $\sigma_r(r) = \frac{P_i a^2}{b^2 - a^2}(1 - \frac{b^2}{r^2})$ and $\sigma_\theta(r) = \frac{P_i a^2}{b^2 - a^2}(1 + \frac{b^2}{r^2})$.
3. Yield Check: At inner bore $r=a$, $\sigma_r(a) = -P_i$, $\sigma_\theta(a) = P_i\frac{b^2 + a^2}{b^2 - a^2}$. von Mises invariant evaluates to $\sigma_{\mathrm{vm}} = \sqrt{3} P_i \frac{b^2}{b^2 - a^2}$.
Case Study 3: SSSS Kirchhoff-Love Plate (Navier Double Sine Series vs Timoshenko) Template: kirchhoff_plate

Problem: Simply supported rectangular plate ($a \times b \times h$) subject to uniform transverse pressure $q_0$. Verify biharmonic deflection series and compare numerical center deflection against Timoshenko's benchmark coefficient ($\alpha = 0.004062$).

1. Navier series term: $w(x, y) = \sum_{m,n} W_{mn} \sin\left(\frac{m\pi x}{a}\right) \sin\left(\frac{n\pi y}{b}\right)$ identically satisfies SSSS boundary conditions.
2. Biharmonic operator: $\nabla^4 w_{mn} = \pi^4 \left[(m/a)^2 + (n/b)^2\right]^2 w_{mn}$. Harmonic amplitude $W_{mn} = \frac{16 q_0}{\pi^6 D m n [(m/a)^2 + (n/b)^2]^2}$.
3. Numerical convergence: Evaluated at $M_{\max}=5, N_{\max}=5$, $w(a/2, b/2)$ matches Timoshenko's tabulated coefficient within about $0.04\%$, producing a stress-colored 3D deflection mesh.
Case Study 4: 2-DOF Structural Vibration & Modal Beat Phenomenon Template: vibration_2dof

Problem: Coupled 2-DOF mass-spring system with mass matrix $\mathbf{M} = \mathrm{diag}(m, m)$ and stiffness matrix $\mathbf{K} = \begin{bmatrix} 2k & -k \\ -k & 2k \end{bmatrix}$. Solve secular equation $\det(\mathbf{K} - \omega^2\mathbf{M}) = 0$, verify mass-orthogonality, and plot modal beats.

1. Natural frequencies: $\omega_1 = \sqrt{k/m}$ (in-phase symmetric mode $\vec{v}_1 = [1, 1]^T$) and $\omega_2 = \sqrt{3k/m}$ (out-of-phase mode $\vec{v}_2 = [1, -1]^T$).
2. Orthogonality check: $\vec{v}_1^T \mathbf{M} \vec{v}_2 = m - m = 0$ (verified identically zero).
3. Response plot: Multi-curve plotter renders modal beat vibrations with interactive frequency sliders.
Case Study 5: TEM Plane Wave Propagation & Radiation Pressure Template: suite_em_maxwell_wave

Problem: A transverse electromagnetic plane wave propagates along $+z$ with fields $\mathbf{E} = [E_0 \cos(kz - \omega t), 0, 0]$ and $\mathbf{B} = [0, \frac{E_0}{c} \cos(kz - \omega t), 0]$. Verify Maxwell's 4 differential equations, Lorenz gauge invariance, and Poynting energy flux.

1. Maxwell verification: Gauss, Gauss Magnetism, Faraday, and AmpÃ¨re-Maxwell residuals are all identically zero when dispersion relation $\omega = c k$ holds.
2. Lorenz gauge: Potential $\mathbf{A} = [-\frac{E_0}{\omega}\sin(kz - \omega t), 0, 0]$ satisfies $\nabla\cdot\mathbf{A} + \frac{1}{c^2}\partial_t V = 0$.
3. Energy & Momentum: Poynting vector $\mathbf{S} = [0, 0, \frac{E_0^2}{\mu_0 c}\cos^2(kz - \omega t)]$, and radiation pressure on absorbing wall $P_{\mathrm{rad}} = \langle u \rangle = \frac{1}{2}\varepsilon_0 E_0^2$.
